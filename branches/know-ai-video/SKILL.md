# 做视频：做之前该懂什么

## 怎么用这份
1. Park 不是视频专家：他会说「电影感」「高级」「震撼」，这些词 AI 收不到任何信息。我负责把它翻成每一镜的开始、动作、结束。
2. 需求含糊 → 用「领域地图」让他挑类型（每类配一个样例），用「先问的问题」问一轮（≤3 个，带推荐默认）；他说「你定」就用默认。
3. 需求已经清楚、或只是一小段 → 直接做，做完说用了哪些默认。
4. 先交给他一张三行以上的分镜表看，确认后再生成；制作交给 hypit、openfilm 或其他生产工具，做完按「好坏标准」自检；被 Park 否了就记进「翻车账」。

## 主干（底层原理，细节都挂在这上面）
1. **一条视频同时排三套结构**：叙事（先告诉观众什么）、镜头（这一刻让观众看哪里）、时间线（同一秒画面、声音、字幕各是什么）。三套没想清就生成，后面一定重做。
2. **信息顺序决定观众想知道什么**：先给结果，观众好奇「怎么发生的」；按时间顺序讲，观众好奇「能不能成」。开头抛出的期待，后面必须回应。数据片先认问题：讲先后用年代，讲扩张用范围，讲高低用高度；不让数字逐个飞入代替解释。
3. **每一镜都要让观众多懂一点**：说不出这一镜多给了什么信息，就删。
4. **画面和声音是两条线**：画面可以换，话接着说；所以计划里「看到什么」和「听到什么」分开写。
5. **按用途分素材，不按长相分**：主线（A-roll）负责把话讲下去、把事演下去；补充（B-roll）负责补细节、交代环境、给情绪、接顺前后。数据成片可由有来源的结构化数据驱动画面；地图、读数与标注须对上同一对象和时期。
6. **Park 管「拍什么」，AI 管「怎么拍」**：事实（名字、数字、必须出现的产品）只能 Park 给，AI 编的事实不可靠；镜头、节奏、配乐是 AI 的活。片子好坏按 **声音 → 节奏 → 镜头 → 导演** 排，好看的单帧只是起点。
7. **风格是一整套语法，不是一层滤镜**：选了水墨，材料、颜色、运镜、转场、配乐乐器都跟着变（水墨用墨晕转场、古琴，不用淡入淡出和钢琴弦乐）。

8. **按画面难点分工**：文字、界面、图形和可参数化的场景适合代码；写实人物与复杂表演用实拍或生成素材，代码管背景与合成。需要还原产品外观时先查有没有真实截图或模型；不为追求全代码牺牲可信度。

## 领域地图（「做个视频」其实分这几类）
| 类 | 一句话 | 样例 / 主线是什么 |
| --- | --- | --- |
| 口播讲解 | 人对镜头讲观点，补充画面穿插 | Park 日常口播；主线 = 他的话，补充 = 截图、录屏、证据 |
| 旁白/图解讲解 | 没人出镜，旁白 + 动画/图形讲清一个概念 | 「三分钟讲懂加息」；主线 = 旁白 |
| 剧情短片 | 有人物、有目标、有阻碍、有结局 | 「赶地铁差一步」的小故事；主线 = 人物行动 |
| 动画 | 手绘 / 水彩 / 3D 卡通 / 动态图形，讲故事或讲概念 | IP 小人演一个比喻；先定风格再定故事 |
| 产品/操作演示 | 演示界面、产品状态、结果 | 工具怎么用；真实操作与效果用截图或录屏，代码可做标注和转场 |
| 氛围/宣传片 | 不讲道理，给情绪和印象 | 品牌片、开场片；主线 = 音乐和节奏 |
| 代码风格短片 | AI 写代码逐帧画，也可与真实或生成的角色素材混合；声音另行制作 | 51 种风格（水墨、皮影、像素 RPG、瑞士排版……），样片在 Studio「素材 Agent」里 |

## 先问的问题（一轮问完）
1. 这条视频看完，观众要明白哪一件事？（从已有材料提 2–3 个候选；推荐：最反直觉的那个）
2. 画面主要靠什么？（选口播 / 旁白图解 / 角色剧情 / 产品演示 / 氛围片；按内容推荐）。做动画或代码短片时，把 3–4 个差异明显的样例并在本题给他挑：像素小人、手绘故事、界面变形、立体产品；写实人物可保留实拍或生成素材，代码只做环境。
3. 节奏和声音选哪种？（快闪卡点 / 抒情慢 / 前慢后快，推荐最后一个；旁白 / 纯音乐 / 已有音轨，讲概念推荐旁白）。开头从问题、结果、冲突画面中给一个推荐；有现成音乐就先按它排节拍。
默认值：30–45 秒；发抖音/小红书竖屏 9:16；字幕用他说话的语言、烧进画面。

## 数据讲解片：替换上面的一轮三问
已有材料能回答的直接填；不多加一轮，也不让 Park 先找齐数据才讨论方向。
1. 想让观众看懂哪种变化？选项：年代先后 / 地盘扩张 / 高度或数量对比 / 多类分布（推荐：只选最能回答主题的一种作主线）。给同一主题的小样让他选，例如「成都历史」可看时间轴、环路外扩、楼高对比。
2. 手里数据支持到哪？选项：有来源和日期的真实数据 / 只有今天的数据 / 只有文章与故事 / 尚未找（推荐：先核对现有材料的年份、范围、单位；只有当代数据时用作空间底图，历史用有出处的事件标注，不假称复原古城）。
3. 先用哪种画面讲？选项：二维地图叠层 / 三维沙盘 / 动态图表 / 现有影像加标注（推荐：能讲清的最简单一种，先做一个关键变化的小样，不默认整城建模）。

## 好坏标准
- 过：前三秒的画面、声音、文字已经交代了要讲的事；内容先用几句话讲顺了（为什么发生 → 中间发生了什么 → 最后怎样）。
- 过：分镜表每一行都有编号、时长、看到什么、听到什么、素材来源、验收点；画面列写看得见的东西，没有「展示重点」「增强情绪」这种空话。
- 过：每个生成镜头有任务单六项——用途、开始、动作、结束、声音、验收。
- 不过：每段单看都好、接起来像素材合集（叙事没排）；台词说完了画面还没到重点（时间线没对齐）；生成了十几段不知道留哪段（没写验收点）；同一信息重复几镜（拖）。
- 风格短片过：一个主体、一个目标、一次转折；前 3 秒有钩子，结尾呼应开头；至少 4 种运镜、一个让人记住的签名镜头放在情绪高点；至少两处真静音在转折前；每个看得见的动作都有声音。
- 风格短片不过：字幕停不到 1.8 秒（也不到「这句念完 + 0.6 秒」）；中文字卡停不到「字数 ÷ 4.5 + 1.5」秒；主体太小或贴边；字幕盖住主体；转场里有黑帧；整片一个速度。
- 两个确认点：先看故事和分镜，再看 2–3 张风格帧；卖点是变形、卡点或人物合成时，第二次还要看几秒动态小样。小样能看清主体、读完字，声音与动作对上，再做全片。

- 代码短片过：最复杂的一小段已试渲并记录耗时，字体、特殊质感和声音已验证；不能用普通镜头的速度估算整片。逐镜检查文字、重叠和衔接，定位到秒后修局部。

- 数据片过：比较时沿用同一底图、单位与比例，变更时明确标出；年份和重点同步，河流或地标保留为定位锚点。只有当代底图时，历史叠层标为示意；不能把今天的楼说成古代建筑。

## 坑
- 只写「电影感、高级、震撼」→ AI 不知道人物该做什么。改成「开始状态 → 动作 → 停在什么状态」，例：盒盖关着 → 角色抬起盒盖 → 盒盖打开并停住。（主干 1）
- 生成了 5 秒不等于要用 5 秒 → 只留合格的那几秒，再查动作完整、首尾好接。（主干 3）
- 截图看不出问题 → 多手指、转头变脸、动作没做完，要整段播一遍才看得出。（主干 3）
- 让 AI「写个视频脚本」只会得到一篇能念的稿子 → 要的是分镜表，不是稿子。（主干 4）
- 演示界面、产品状态、实验结果用 AI 生成 → 不可信，必须真实截图/录屏；表里提前写清来源。（主干 5）
- 换镜头没理由 → 换镜只为四件事：交代位置、展示动作、突出细节、看反应。（主干 3）
- 一个风格想到的第一个点子往往是它的俗套 → 先写三个候选结构再挑；做完和作者样片比（结构、开场、签名镜头、运镜、配乐、结尾），六项至少四项不同。（主干 7）
- 给 AI 说「电影感」没用 → 给一个对标（「像 60 年代 007 片头」「节奏学 Edgar Wright」），只学语法不抄画面；对标比任何规则都提质量。（主干 6）
- 反馈说「节奏不对」没用 → 说到秒：「第 12 秒摔倒太快看不懂」。（主干 3）
- 照作者样片的代码换内容，比从零写稳得多；但样片里的人名、品牌、角色不能带进 Park 的片子。（主干 7）

- 把所有人物表演都交给代码 → 先分清人物素材与场景动效；产品外形要准确，就给真实截图或模型。（主干 8）
- 静帧漂亮就开渲整片 → 卡点、变形、抠像边缘要看动态小样；复杂材质先试渲，耗时增加再决定保留多少。（主干 7–8）

## 词表（行话 ↔ 大白话）
- 帧 = 暂停时看到的那一张；镜头 = 一段连续没切的画面；场景/一场戏 = 同一时间地点的一件事；段落 = 几场戏讲完一件大事
- 素材 = 原料文件（一个文件里可能有好几个镜头）；片段/Clip = 剪辑软件里能拖动的一块
- A-roll = 主线；B-roll = 补充画面；空镜 = 没人的环境/物件；插入镜头 = 凑近看一个细节；切离镜头 = 暂时去看旁边的人或物
- 脚本 = 内容怎么展开的文字计划；分镜图 = 每格一张草图；分镜表 = 一行一个镜头的表；镜头清单 = 要拍/要生成的待办；风格参考板 = 几张参考图放一起定调子
- 时间线 = 剪辑软件里从左到右的时间表，画面、配音、音乐、字幕各占一行
- cue map / 卡点表 = 每个切镜、动作、字幕落在音乐的哪一拍；风格帧 = 从片子里先画出来的 2–3 张定调画面；签名镜头 = 让人记住的那一个镜头
