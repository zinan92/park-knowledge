# 把别人的作图 skill 改成自己的

- 骨架可以是别人的，翻车必须是自己的。先原样跑 3–5 个真实任务，记现象不记结论（「字变打印体」是现象，「模型不行」是结论）。
- 三刀，由浅到深，每刀改完测一次：① 调参数（色号、比例、数量）② 改描述（用动作词替换风格词）③ 换 IP（角色定义整个换成自己的，配过/不过测试）。
- 每次只改一处；改动超过一半就直接重做。
- 锚点和变量分开写；跨两个以上风格重复的经验抽成一个共享文件，用编号引用，避免同一条改漏。
- 剃刀：这句删掉 AI 会做错吗？不会就删。SKILL.md 末尾写「什么时候读哪个参考文件」。
- 建失败记录表：日期 / 翻车现象 / 新增约束。规则被新场景推翻时，划适用域，不硬套。
- 看开源协议，尊重原作者。
