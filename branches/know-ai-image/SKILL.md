# AI 作图：做之前该懂什么

## 怎么用这份
1. Park 不是作图专家：他会说「好看点」「高级点」，这些词模型收不到任何信息。我负责把它翻成数字、动作、禁止。
2. 需求含糊 → 用「领域地图」让他挑类型，用「先问的问题」问一轮（≤3 个，带推荐默认）；他说「你定」就用默认。
3. 给自己的文章配图、风格已固定（Park IP、白纸手绘）→ 不问，直接交给 park-ip-illustrations，只先想清比喻。
4. 出图交给生产 skill；做完按「好坏标准」自检，一次出多张让他挑，不替他预筛；被 Park 否了就记进「翻车账」。

## 主干（底层原理，细节都挂在这上面）
1. **比喻是产品，渲染只是执行**：画面先要说清一个意思，再谈好不好看。
2. **模型听得懂数字、动作、禁止，听不懂审美**：品味必须翻译成这三种形态。
3. **正向要求模型都知道，负面边界才是专家经验**：值钱的是「不许什么」。
4. **锚点和变量分开**：不变的写死，可变的才放开，否则要么僵死要么失忆。
5. **生成便宜、挑选靠人**：多出候选让 Park 挑，在选中的上微调，不推倒重来。

## 领域地图（一张图其实分这几类）
| 类 | 一句话 | 适合 |
| --- | --- | --- |
| 概念图 | 一个比喻画面讲一个观点，大留白 | 文章正文、观点帖 |
| 信息图 | 流程 / 对比 / 层级 / 时间线 / 数据，横版 | 讲清结构、方法论 |
| 恶搞科普长图 | 用最俗的东西解释最玄的，竖版 | 技术概念科普、涨粉 |
| 多格漫画 | 几格讲一个过程或小故事 | 讲经历、讲过程 |
| 封面 | 必须放完整标题，按发布比例裁切 | 视频 / 长文封面 |
| 生活感照片 | 像真人随手拍，一次一组 | 人设、氛围（不能当证据） |

## 先问的问题（一轮问完）
1. 这张图要让人一眼看懂哪**一个**意思？（我先从文章里找出一组张力给他选：多 vs 一、空 vs 暖、生成 vs 判断……推荐：最反直觉的那组）
2. 哪一类？（上表选一，推荐按用途默认：正文→概念图，结构→信息图，封面→封面）
3. 放哪个平台、什么比例？（推荐：按发布平台默认比例，封面按实际裁切检查）

## 好坏标准
- 过：比喻不用解释就懂；一图一意；有动作场景而不是漂浮符号；物件大、人小，尺度差明显；点缀色只落在「这张图在讲什么」的那个元素上。
- 过：多张图像同一个人画的（锚点描述在提示词开头、角色锁定块逐字复用、参考图上传）。
- 不过：比喻概念对但不好笑/不打动（太体面，没有降维落差，例：API = 餐厅菜单）；人物占半屏；手绘画面里出现打印体字；画面挤满没留白；出现渐变、阴影、3D。

## 坑（别人翻过的车）
- 风格词无效 → 品味要翻成三种形态：**数字**（人物占画面 1/12–1/10、留白 ≥40%、画面中文 ≤6 字）、**动作**（「钢笔手写，字迹歪斜，大小不一，笔触顿挫」，不写「手写字体」）、**禁止**（写死色号；关键元素至少枚举 6 个不许的变体）。
- 中文超 6 字几乎必乱码，超 8 字几乎必败 → 拆短或后期叠字；封面标题例外，完整优先，逐字校对。
- 负面约束在长提示词里会被忘 → 核心禁止项在开头和排版区各写一次。
- 「荒诞场景」得到一张中性脸 → 显式写表情夸张程度。
- 描述有歧义会被极简没了（躯干被省成火柴人）→ 写到不可歧义，再配一条过/不过测试。
- 描述词到头了 → 给参考图（字形、角色），只参考形，不抄文案排版。
- Park 说「不对」→ 不推倒重写，把反馈翻成更强的约束放到提示词开头，在选中的那张上微调。
- 多页任务 → 先出封面和第一页锁方向，确认后再批量，每 3–5 页停一次。
- 提示词写成参数表会有机器味 → 照片类写成一段 80–150 字的人话。

## 词表（行话 ↔ 大白话）
- 锚点 = 每张都不能变的东西（颜色、人物长相、比例）
- 变量 = 每张可以换的（比喻、场景、文案）
- 负面提示 = 不许出现什么
- 角色锁定块 = 一段 20–40 字的人物描述，每张图逐字复制
- 版式骨架 = 现成排版套路，选一个填内容，不让 AI 自己发明
